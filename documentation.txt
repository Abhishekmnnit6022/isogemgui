CORE PACKAGE (core/)

File: core/bezier.py
Description:
Pure math functions for Bernstein polynomials, arbitrary degree 2D and 3D Bezier curves, and 3D tensor-product Bezier surfaces.
Functions:
- bernstein(i, n, u):
  Calculates the value of the i-th Bernstein basis polynomial of degree n for an array of parameter values u in [0, 1].
- bezier_curve(control_points, n_eval=200):
  Takes an array of control points (2D or 3D) and returns points along the Bezier curve evaluated at n_eval parameter steps.
- bezier_surface(net, u_eval=30, v_eval=30):
  Takes a 3D control net grid of shape (rows, cols, 3) and computes the X, Y, and Z matrices of the evaluated 3D surface.

File: core/bspline.py
Description:
Pure math functions for B-spline basis functions and curve evaluation using the Cox-de Boor recursion algorithm.
Functions:
- _basis_scalar(i, p, u, knots):
  Recursively calculates the value of the i-th B-spline basis function of degree p at a single parameter value u. Handles zero division and includes the right endpoint u == knots[-1].
- basis_matrix(knots, degree, n_eval=200):
  Generates a matrix of all basis functions evaluated over an evenly spaced parameter array from the first knot to the last knot.
- basis_functions(knots, degree, u):
  Vectorised Cox-de Boor: every N_{i,p} at an array of parameters at once (same rules as _basis_scalar).
- valid_domain(knots, degree):
  Returns (knots[p], knots[-p-1]), the range where the basis sums to 1 and the curve is defined.
- bspline_curve(knots, degree, control_points, n_eval=200, u_values=None):
  Multiplies the evaluated basis functions with the control points to return the coordinates of points along the B-spline curve, sampled on its valid range.

File: core/nurbs.py
Description:
Pure math functions for rational basis calculation, arbitrary-degree 2D/3D NURBS curves, and 3D NURBS surfaces. Includes standard circle and cylinder generators. Reuses Cox-de Boor from core.bspline.
Functions:
- rational_basis_matrix(knots, degree, weights, n_eval=200):
  Computes rational basis functions R_i(u) = N_i(u) * w_i / sum_j (N_j(u) * w_j).
- nurbs_curve(knots, degree, control_points, weights, n_eval=200):
  Evaluates 2D or 3D NURBS curve points C(u) = sum_i R_i(u) * P_i.
- nurbs_surface(knots_u, knots_v, degree_u, degree_v, net, weights, n_eval_u=30, n_eval_v=30):
  Evaluates 3D NURBS surface points S(u, v) = sum_{i,j} R_{i,j}(u, v) * P_{i,j} and returns X, Y, Z coordinate grids.
- nurbs_circle(radius=1.0, center=(0.0, 0.0)):
  Generates standard 9-point quadratic NURBS circle with alternating weights 1 and sqrt(2)/2.
- nurbs_cylinder(radius=1.0, height=1.0):
  Generates extruded cylinder surface (degree 2 along u, degree 1 along v), built with extrude_curve.
- extrude_curve(control_points, weights, knots, degree, height=1.0):
  Sweeps a 2D NURBS curve along z into a NURBS surface (curve along u, linear along v).
- t_profile(flange_width=4, flange_thickness=1, stem_width=1, stem_height=3, fillet_radius=0.4):
  Closed T cross-section as a degree-2 NURBS curve: straight edges and two exact quarter-circle
  fillets at the inner corners, joined by double knots (21 control points; 17 when fillet_radius=0).
- nurbs_t_shape(..., depth=1.0):
  3D T-shape surface: t_profile extruded along z (21x2 net, degree 2x1).
- sample_parameters(knots, n_eval=200):
  Evenly spaced parameters merged with every distinct knot, so sharp corners are evaluated exactly.
- fit_circle(points):
  Least-squares circle through 2D points; returns (cx, cy, radius, max_radius_error).
Note: nurbs_curve and nurbs_surface also accept explicit parameter values (u_values / v_values).
nurbs_surface computes each direction's basis once and combines them with NumPy.

File: core/knots.py
Description:
Generators for standard knot vectors used in B-spline curves.
Functions:
- open_uniform(n_control_points, degree):
  Generates a clamped open uniform knot vector where the first (degree + 1) knots are 0 and the last (degree + 1) knots are 1, with evenly spaced values in between. This makes the curve pass through the first and last control points.
- uniform(n_control_points, degree):
  Generates an integer sequence of knots 0, 1, 2, ..., n + p, used for periodic or uniform B-splines.

File: core/validation.py
Description:
Input checking functions that verify data before calculation, raising clear ValueError messages if something is wrong.
Functions:
- validate_knots(knots):
  Verifies that knots are in non-decreasing order and that there are at least 2 knots.
- validate_degree(degree):
  Verifies that the polynomial degree is an integer greater than or equal to 0.
- validate_control_points(points):
  Verifies that control points form a valid 2D array with either 2 or 3 columns (X, Y or X, Y, Z).
- validate_bspline_params(knots, degree, n_control_points):
  Verifies the B-spline rule: len(knots) must equal n_control_points + degree + 1.
- validate_surface_net(net):
  Verifies that a surface control net has shape (rows, cols, 3) and is at least 2x2.
- validate_weights(weights, expected_len):
  Verifies that curve weights are strictly positive numbers and match the control points count.
- validate_surface_weights(weights, expected_rows, expected_cols):
  Verifies that surface weights are strictly positive 2D array matching the control net shape.

File: core/io_json.py
Description:
Handles saving and loading curve and surface data to and from JSON files, supporting Bézier, B-spline, and NURBS.
Functions:
- _make_weights(n):
  Creates a list of 1.0 weights for all points as default.
- save(path, data):
  Saves geometry dictionaries (control points, degree, knots, weights, etc.) into a JSON file.
- load(path):
  Reads a JSON file, validates its fields, and returns a verified dictionary with numpy arrays. Supports nurbs_curve and nurbs_surface schemas, and "iga_analysis_model" files exported from the IGA Analysis tab (its "geometry" is validated as a nurbs_surface; boundary conditions are checked and returned as data["conditions"]).

File: core/refinement.py
Description:
Knot insertion (Boehm's algorithm) in homogeneous coordinates (w*x, w*y, w*z, w), so B-splines and
NURBS are refined the same way. The geometry never changes; only control points are added.
Functions:
- insert_knot(knots, degree, control_points, u, times=1, weights=None):
  Inserts u (times times) into a curve. u must lie strictly inside the valid range and its total
  multiplicity may not exceed the degree. Returns (knots, control_points, weights or None).
- refine_uniform(knots, degree, control_points, weights=None):
  Splits every element in two (inserts each knot-span midpoint once).
- insert_knot_surface(knots_u, knots_v, degree_u, degree_v, net, weights, direction, value, times=1):
  Inserts a knot in "u" (adds a row of control points) or "v" (adds a column).
- refine_surface_uniform(..., direction="both"): splits every element in u, v or both.

File: core/analysis.py
Description:
IGA analysis preparation for a NURBS surface, without a solver. Control points are numbered
index = i * n_cols + j (i along u, j along v), 0-based (1-based in the MATLAB export).
Functions / classes:
- surface_derivatives(ku, kv, du, dv, net, weights, u, v): S, S_u, S_v on a parameter grid
  (rational quotient rule on the weighted sums).
- is_planar(net), jacobian(Su, Sv, planar): signed det J = x_u y_v - x_v y_u for planar surfaces,
  area stretch |S_u x S_v| otherwise. gauss_legendre(n), is_clamped(knots, degree).
- analyze_surface(ku, kv, du, dv, net, weights, n_gauss_u=None, n_gauss_v=None, conditions=None)
  -> AnalysisModel. Elements are the non-empty knot spans in u times those in v. For each element:
  parameter ranges, the (p+1)(q+1) control points acting on it (connectivity), area by Gauss
  quadrature (default p+1 by q+1 points), min/max Jacobian at the Gauss points and just inside
  the corners, and a status: OK, Distorted (max|J|/min|J| > 10), Inverted (planar and
  det J <= 0) or Degenerate (|J| almost 0, e.g. an edge collapsed to a point).
  Also: boundary control-point sets for the edges u = 0, u = 1, v = 0, v = 1, Gauss point
  positions, total area, and whether the knots are clamped.
- AnalysisModel.dofs(): unknowns for a scalar field, 2D elasticity and 3D; quality_counts();
  to_dict() (the JSON layout, type "iga_analysis_model").
- jacobian_field(model, per_element): fine grid of points and Jacobian values for colouring.
- element_mesh_lines(ku, kv, du, dv, net, weights): iso-curves along every element boundary.
- export_json(model, path); export_matlab(model, path): MATLAB/Octave script with
  geometry.form/dim/number/coefs/knots/order in the NURBS toolbox (nrbmak / GeoPDEs) layout
  (coefs = 4 x n_u x n_v weighted coordinates), elements (ranges, 1-based connectivity, area,
  Jacobian range, status), dofs and boundaries(k).name/control_points/condition.

Also added for this feature:
- core/bspline.py: basis_function_derivatives(knots, degree, u) and element_boundaries(knots, degree).
- core/nurbs.py: quarter_annulus(inner_radius=1, outer_radius=2) and plate_with_hole(radius=1,
  length=4), the classic planar IGA benchmark geometries (exact circular arcs, positive Jacobian).

File: ui/analysis_tab.py
Description:
The IGA Analysis tab. Prepares a NURBS surface for isogeometric analysis (no solver). The left
panel is a scrollable column of five numbered group boxes so each job is clearly separate:
  Step 1 - Geometry: Use NURBS Surface Tab, Open File..., or an example (plate with a hole,
           quarter annulus, cylinder, T-shape).
  Step 2 - Refinement (shape is kept): split every element in U / V / both, insert a knot at a
           value in U or V, Reset to Original Geometry. Refinement above 10000 elements is refused.
  Step 3 - Boundary Conditions: table of the four edges (u = 0, u = 1, v = 0, v = 1) with the
           number of control points on each and a condition combo (Free, Fixed (Dirichlet),
           Load (Neumann), Symmetry). Selecting a row highlights the edge and its control points.
  Step 4 - Display: element mesh, Jacobian colours, boundary conditions, element numbers,
           control net, Gauss points.
  Step 5 - Export: Export JSON... and Export MATLAB (.m)...
The right side shows the plot (2D for planar surfaces, 3D otherwise) above a results area with a
"Summary" tab (monospaced text) and an "Elements" table (click a row to outline the element and
its control points; the Status cell is coloured).
Functions / Methods:
- set_geometry(net, weights, knots_u, knots_v, degree_u, degree_v, source, conditions=None):
  validates and loads a new starting geometry.
- _load_from_surface_tab(), _open_file(path=None), _load_example(): Step 1 sources.
- _split(direction), _insert(), _reset_refinement(): Step 2.
- _on_condition_changed(), _on_edge_selected(), _on_element_selected(): Step 3 and selection.
- _rebuild(): runs core.analysis.analyze_surface and refreshes labels, tables, summary and plot.
- summary_text(): the Summary text.
- _draw(): Jacobian colouring, mesh lines, flagged elements, control net, Gauss points,
  boundary conditions, element numbers and highlight.
- export_json(path=None), export_matlab(path=None): Step 5.
- get_data() / set_data(data) / reset(): File -> Save As / Open / New integration
  (type "iga_analysis_model").

3. WHAT LOGIC CHANGED FROM PREVIOUS CODE
================================================================================

1. In-Process Execution instead of Subprocesses:
   - Previously: main.py was a launcher that spawned external scripts using Python subprocesses (subprocess.Popen). Many scripts opened separate console windows or standalone dialogs.
   - Now: Everything runs inside one single window with 3 tabs. Calculations are called directly as in-memory Python functions.

2. Fixed Deprecated NumPy Functions:
   - Previously: Scripts used np.math.factorial or np.math.comb. In modern NumPy versions (2.0+), np.math has been removed and causes crash errors.
   - Now: Replaced with the standard Python math.comb function, which is fast, exact, and works on all Python versions.

3. Right-Endpoint Inclusion in B-Splines:
   - Previously: Cox-de Boor implementations used strict inequality (knots[i] <= u < knots[i+1]). When u reached the last knot (e.g. u = 1.0 or u = 5.0), all basis functions became 0, so the curve dropped to (0, 0) instead of reaching the last control point.
   - Now: An explicit check includes u == knots[-1] for the last active span, allowing clamped curves to touch the final control point as mathematically intended.

4. Unified B-Spline Basis Function Calculation:
   - Previously: There were multiple separate files (Basis_function.py, Bspline_Basis_function.py, Basis_test.py, BsplineCurve02.py) with slightly different implementations.
   - Now: Merged into one thoroughly tested, robust implementation in core/bspline.py.

5. Unified Excel Export:
   - Previously: Data_Store.py was a standalone script writing a hardcoded matrix to an Excel file path.
   - Now: Integrated as an interactive button on the B-spline tab and a menu item under File -> "Export basis matrix to Excel...". It lets the user choose any file destination and writes the computed basis matrix with column names.

6. Arbitrary Degree Bezier Curves:
   - Previously: There were separate files for 1st degree, 2nd degree, 3rd degree, and 3D cubic curves.
   - Now: One single formula evaluates any degree (from degree 1 up to high degrees) in both 2D and 3D.

7. NURBS Curves and Surfaces Extension (Objective 1):
   - Added pure-math NURBS engine in core/nurbs.py implementing rational basis functions R_i(u) = N_i(u)*w_i / sum(N_j(u)*w_j).
   - Reused Cox-de Boor recursion from core.bspline without code duplication.

4. WAS THE MATHEMATICS CHANGED OR NOT?
================================================================================

NO. The mathematics was NOT changed.
The underlying mathematical formulas remain identical:
- Bezier curves still use Bernstein polynomials:
    B_{i,n}(u) = C(n, i) * u^i * (1 - u)^(n - i)
- Bezier surfaces still use tensor products of Bernstein polynomials:
    S(u, v) = sum_i sum_j B_{i,n}(u) * B_{j,m}(v) * P_{i,j}
- B-splines still use the standard Cox-de Boor recurrence relation:
    N_{i,0}(u) = 1 if knots[i] <= u < knots[i+1], else 0
    N_{i,p}(u) = ((u - knots[i]) / (knots[i+p] - knots[i])) * N_{i,p-1}(u)
               + ((knots[i+p+1] - u) / (knots[i+p+1] - knots[i+1])) * N_{i+1,p-1}(u)
    with 0/0 defined as 0.
- NURBS strictly extends the B-spline foundation by adding positive weights w_i:
    R_i(u) = (N_i(u) * w_i) / sum_j (N_j(u) * w_j)
  When all weights w_i = 1, NURBS mathematically simplifies exactly to standard B-splines.
- All evaluation results were checked against the Matlab validation scripts and give identical numerical results.

7.2 NUMERICAL PRECISION & EXACT CONIC GEOMETRY
--------------------------------------------------------------------------------
Polynomial curves (Bézier and standard B-spline) cannot represent conic sections (circles, ellipses, hyperbolas, cylinders) exactly without approximation error. Rational B-splines (NURBS) solve this fundamentally by assigning homogeneous weights w_i to control points:
  R_i(u) = (N_i(u) * w_i) / (sum_j N_j(u) * w_j)

Evaluation results from the automated test suite demonstrate machine-level precision:

1. Standard 9-Point Quadratic Exact Circle (radius = 1.0, center = (0.0, 0.0)):
   - Evaluated at 400 uniform steps over u in [0, 1]:
   - Theoretical radius: 1.0000000000000000
   - Maximum radius error: |sqrt(x^2 + y^2) - 1.0| = 2.22e-16 (machine epsilon)

2. Shifted and Scaled Circle (radius = 2.5, center = (3.0, -4.0)):
   - Evaluated at 400 uniform steps over u in [0, 1]:
   - Theoretical radius: 2.5000000000000000
   - Maximum radius error: 1.33e-15

3. Quarter Circle Midpoint (u = 0.5):
   - Theoretical coordinate: (sqrt(2)/2, sqrt(2)/2) = (0.7071067811865476, 0.7071067811865476)
   - Evaluated coordinate error: < 1.0e-15

4. Extruded Cylinder Surface (radius = 1.0, height = 1.0):
   - Evaluated on a 30x30 parameter grid:
   - All evaluated surface points satisfy |x^2 + y^2 - 1.0| < 1.0e-12
   - All z coordinates lie strictly within [0.0, 1.0]
